# date-request

A six-step date proposal, delivered as a website instead of a text message.

- The **no** button flinches, then runs, then leaves entirely. It never turns into a yes.
- Certainty slider (rigged), food roulette, a fake fee that refunds itself, and a signature pad.
- Sound effects, haptics, dark mode, `prefers-reduced-motion` respected.

**Personalise it:** add `?to=Name` to the URL.

No backend, no analytics, no data leaves the page.
